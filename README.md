# Dashboard Brasileirão - Power BI

## 📊 Sobre o projeto
Dashboard interativo desenvolvido no Power BI com dados do Brasileirão.

## 🔎 Funcionalidades
- Desempenho dos times (pontos, vitórias, derrotas)
- Estatísticas de gols (marcados e sofridos)
- Comparação entre temporadas
- Filtros por time e temporada
- Visualização de rankings e indicadores (KPIs)

## 🛠️ Ferramentas
- Power BI

## 📂 Base de Dados
Os dados utilizados neste projeto foram obtidos através das seguintes fontes:

- Histórico oficial do Brasileirão:  
  https://www.terra.com.br/esportes/futebol/brasileiro-serie-a/tabela/

- Dataset com dados das temporadas de 2008 a 2019:  
  https://www.kaggle.com/datasets/davidantonioteixeira/brasileirao2008-2019
