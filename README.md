# Dashboard Brasileirão - Power BI

## 📊 Sobre o projeto
Dashboard interativo desenvolvido no Power BI com dados do Brasileirão.

## 🔎 Funcionalidades
- Desempenho dos times (pontos, vitórias, derrotas)
- Estatísticas de gols (marcados e sofridos)
- Comparação entre temporadas
- Filtros por time e temporada
- Visualização de rankings e indicadores (KPIs)

## 🛠️ Ferramentas
- Power BI
